Manage optional models from Reading Helper, and practise saved words and sentences.

- Add Models & voices: detect existing components, explicitly download or verify/repair missing ones, pause/resume downloads, and deliver future catalogue additions through signed application updates. No terminal is needed for subsequent supported components after first-time helper setup.
- Pin model artifact checksums and catalogue identities. Reuse compatible files, stage changes, retain a previous version and recover interrupted activation. Application updates and preparation are protected from concurrent component installation.
- Add a local study library with course/type filters, search, bookmarks and a direct practice action on course words and sentences.
- Reveal Romaji per word or together. Repeat complete original recordings with adjustable pauses, repetition count and speed.
- Record a short local take and compare it with the original. Microphone access is explicit, recordings stay in page memory, and no automatic pronunciation score is claimed.
- Include component download state in diagnostics. Compatible voice recordings, settings and course results are retained; no large model download starts merely by installing this update or visiting a course.

Includes helper 1.20.0. Browser permissions are unchanged. First-time helper registration still uses Setup.cmd; new/missing supported components can then be installed from the Models & voices page. Model download sizes and per-file time estimates are shown before/during the explicit installation. The app update does not silently install models.
