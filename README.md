# iKnow! Reading Helper · 1.34.0

Unpacked Windows11 / Brave release. One Setup.cmd menu installs all components or just the Mao Plain / Nise voices, and handles repairs. Successful setup ends with the ilyasnsir1 creator banner.

Version1.34.0 adds Updates in the extension popup. Public GitHub releases need no GitHub account on the receiving PC. Update packages are checked against the publisher's pinned signing key and per-file hashes before application files are replaced at their existing location. Settings, models and prepared courses are retained. Install this first updater-enabled version manually; later compatible releases can be installed from the popup. See UPDATES.md.

Read [START-HERE.md](START-HERE.md) for the quick installation or [SHARE-WITH-A-FRIEND.md](SHARE-WITH-A-FRIEND.md) for the full step-by-step guide. Downloads: https://github.com/ilyasnsir1/iknow-reading-helper/releases/latest

For a setup video, see [RECORDING-A-FRESH-INSTALL.md](RECORDING-A-FRESH-INSTALL.md). A separate Windows account provides fresh setup state without removing the main installation.

This folder includes the extension, setup scripts, reviewed course data and license notices. It does not include browser profiles, personal settings, prepared personal caches, model downloads or development previews.
