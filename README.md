# iKnow Reading Helper

A small helper I made for studying Japanese on iKnow.

It adds Romaji, German translations, meaning colors and word audio.
Saved words and sentences can be practised in the study library, along with
course tests and Hiragana/Katakana exercises.

## Install

For Windows and Brave (or Chrome).

1. Download the [latest release](https://github.com/ilyasnsir1/iknow-reading-helper/releases/latest) and extract it to a permanent folder.
2. Open `brave://extensions`, enable Developer mode and choose **Load unpacked**. Select the extracted `extension` folder.
3. Run `helper/Setup.cmd` and follow the setup menu.
4. Reload the extension, then open an iKnow course.

Later updates can be installed from the extension popup. Keep the folder in the
same place so your browser and local helper can find it.
